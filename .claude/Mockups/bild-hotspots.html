Bild-Hotspots

Editor & Ausspielung · interaktives Element

Nutzer platzieren im Editor Punkt-Hotspots auf einem Bild und hinterlegen Titel & Text. In der Ausspielung fährt der Lernende über die Hotspots und bekommt den passenden Text angezeigt. Positionen werden prozentual gespeichert → responsiv & unabhängig von der Anzeigegröße.

So sieht die Produktion mit Annotorious aus

        

            Dieser Mockup nutzt eine schlanke Vanilla-Implementierung, damit er ohne Build-Schritt läuft.
            Die Interaktion & das Datenmodell sind 1:1 auf @annotorious/react übertragbar:
        

        
    
            
  • Editor → <ImageAnnotator tool="point"> um das <img>; Klick erzeugt Annotation, Text ins Body-Feld.
    • 
            
  • Ausspielung → gleiche Komponente read-only, onMouseEnter rendert euren Tooltip.
    • 
            
  • Speichern → anno.getAnnotations() liefert W3C-Web-Annotation-JSON (statt localStorage euer Backend).
    • 
            
  • Koordinaten → beim Speichern in Prozent umrechnen (x / imageWidth), damit Hotspots bei jeder Größe sitzen.
